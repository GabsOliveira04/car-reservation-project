🚗 Car Reservation System

📌 Descrição

Esse código cria a estrutura completa do sistema de reserva de carros. Na prática, 
ele organiza onde e como cada informação vai ser guardada: os dados dos clientes, 
os veículos disponíveis, as filiais de retirada e devolução, os tipos de carro com 
seus valores de diária e todos os dados de cada reserva feita. Ele também conecta essas 
informações entre si — por exemplo, saber exatamente qual cliente alugou qual carro, em qual filial, 
as datas, o valor e a situação do aluguel. É a base sobre a qual o sistema vai funcionar: sem essa estrutura organizada, 
não é possível controlar, buscar ou gerenciar as reservas de forma confiável.

📂 Arquivos
 `criar-tabelas.sql` — Estrutura das tabelas
`inserir-dados.sql` — Cadastro de dados de exemplo
 `consultas.sql` — Buscas e relatórios do sistema

 🛠️ Tecnologia
- MySQL
